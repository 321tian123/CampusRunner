## 1. 环境准备

### 1.1 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 (64 位) |
| 模拟器 | 雷电模拟器 9 (LDPlayer 9) |
| 运动 App | Keep (或其他支持 GPS 的运动 App) |

### 1.2 雷电模拟器设置

**第一步：开启 USB 调试**

1. 打开雷电模拟器 9
2. 点击右侧工具栏 **「设置」**（齿轮图标）
3. 点击 **「其他设置」**
4. 找到 **「ROOT 权限」** → 选择「开启」
5. 找到 **「ADB 调试」** → 选择「开启本地连接」

**第二步：安装 Google Play Services（重要！）**

Keep 等运动 App 依赖 Google 位置服务。必须安装：

1. 雷电模拟器桌面 → 打开 **「系统应用」** 文件夹
2. 找到并打开 **「Google 安装器」**
3. 按照提示完成 Google Play Services 安装
4. 安装完成后重启模拟器
5. 登录 Google 账号（可选，但建议）

**验证 Google 服务是否安装成功**：

- 模拟器中打开 **Google Play 商店**，如果能正常打开，说明安装成功
- 如果闪退或无法打开，说明需要重新安装

**第三步：安装运动 App**

1. 在模拟器中打开 **Google Play 商店** 或 **应用商店**
2. 搜索 **Keep**（或你使用的其他运动 App）
3. 安装并登录

### 1.3 ADB 准备

CampusRunner 需要 ADB（Android Debug Bridge）来与模拟器通信。

雷电模拟器 9 自带 ADB，位于安装目录下（如 `D:\leidian\LDPlayer9\adb.exe`）。

如果你使用的是独立 ADB，确保在 `config.json` 中配置正确路径。

## 2. 安装与启动

### 方式一：使用打包好的 EXE（推荐）

1. 下载 `CampusRunner.exe`
2. 将 `CampusRunner.exe` 放入任意文件夹
3. 在同目录下创建 `config.json`（可先用默认配置）
4. 在同目录下创建 `routes` 文件夹
5. 双击 `CampusRunner.exe` 运行

### 方式二：Python 源码运行

```bash
# 安装依赖
pip install customtkinter tkintermapview

# 启动（默认 Soft UI 界面）
python main.py

# 启动旧版界面
python main.py --classic

# 启动最旧版界面
python main.py --legacy
```

### 方式三：从源码打包 EXE

```bash
python build_exe.py
# 输出文件：dist/CampusRunner.exe
```

## 4. 连接模拟器

### 4.1 自动连接

软件启动后会自动尝试连接模拟器。连接成功时：
- 顶部右侧显示 **「● 已连接」**（绿色）
- 侧边栏底部显示 **「● 已连接」**
- 连接按钮变为 **「断开」**（红色）

### 4.2 手动连接

如果自动连接失败：

1. 点击侧边栏 **「⚙ 设置」**
2. 确认以下配置：
   - **ADB 路径**：雷电模拟器 ADB 路径（如 `D:/leidian/LDPlayer9/adb.exe` 或 `D:/op/adb.exe`）
   - **设备地址**：默认为 `emulator-5554`
3. 点击 **「保存」**
4. 点击底部 **「连接模拟器」**

### 4.3 连接失败排查

| 现象 | 解决方法 |
|------|----------|
| 找不到 ADB | 确认 `config.json` 中 `adb_path` 路径正确 |
| 连接超时 | 检查模拟器是否已启动、USB 调试是否开启 |
| 设备未授权 | 模拟器可能弹出授权对话框，点击「允许」 |
| 端口被占用 | 尝试重启模拟器 |

### 4.4 验证连接

可以在命令行中手动验证：

```bash
adb devices
# 应显示：emulator-5554   device
```

## 5. 路线规划

### 5.1 手绘路线（推荐）

这是最灵活的方式，特别适合校园操场等 Amap API 覆盖不全的场景。

1. 在地图工具栏点击 **「✏ 绘制路线」**
2. 在地图上**左键点击**添加路径点
3. 每个点会用数字标记，点之间自动连线显示
4. **右键**可以撤销最后一个点
5. 点击 **「✓ 完成路线」** 结束绘制
6. 路线自动生成为 Route 对象，可立即使用

**提示**：
- 至少需要 2 个点才能完成
- 可在操场跑道上顺时针点击 4-6 个点来创建环形路线
- 按学校实际道路点出跑步路线更真实

### 5.2 高德地图搜索

使用真实道路数据生成路线。

1. 确保已在设置中配置 **高德 API Key**（见 [第11章](#11-高德地图-api-配置)）
2. 在底部控制栏输入：
   - **起点**：格式 `经度,纬度` 或地址文本（如 `116.3264,39.9923` 或 `北京大学`）
   - **终点**：同上
3. 点击 **「搜索路线」**
4. 获取成功后地图显示蓝色路线轨迹

**提示**：
- 高德返回步行/骑行道路路径，自动避开高速和立交
- 免费额度 5000 次/日，个人使用绰绰有余

### 5.3 快速生成跑道

点击底部 **「生成跑道」**，自动创建一条 2km 校园风格环形路线。

路线以 `config.json` 中 `center_lat`、`center_lng` 为中心，椭圆+随机弯曲模拟真实路径。

### 5.4 加载已保存的路线

1. 点击底部 **「加载路线」**
2. 选择 `.json` 或 `.gpx` 格式的路线文件
3. 路线加载后自动在地图上显示

## 6. 配速与目标设置

### 6.1 三者联动规则

CampusRunner 采用**三选二**联动机制：

| 设置项 | 说明 | 示例 |
|--------|------|------|
| 距离 (km) | 跑步目标距离 | 5.00 km |
| 配速 (min/km) | 每公里用时 | 6'00" /km |
| 时间 | 预估总时间（自动计算） | ≈ 30:00 |

- 修改**距离** + **配速** → 自动计算时间
- 修改**距离** + **时间** → 自动计算配速
- 修改**配速** + **时间** → 自动计算距离

### 6.2 配速参考

| 运动类型 | 配速范围 | 速度范围 |
|----------|----------|----------|
| 快走 | 8'00" ~ 10'00" | 6 ~ 7.5 km/h |
| 慢跑 | 6'00" ~ 7'30" | 8 ~ 10 km/h |
| 跑步 | 5'00" ~ 6'00" | 10 ~ 12 km/h |
| 快跑 | 4'00" ~ 5'00" | 12 ~ 15 km/h |
| 冲刺 | 3'00" ~ 4'00" | 15 ~ 20 km/h |

**校园跑推荐配速**：6'00" ~ 7'00" /km（8.5 ~ 10 km/h），既不太快也不太慢，真实自然。

## 7. 开始跑步

### 7.1 操作步骤

1. 确认模拟器已连接（侧边栏显示 ●）
2. 确认路线已加载（地图上显示蓝色轨迹）
3. 确认目标已设置（距离 + 配速）
4. 可选：勾选 **「☑ 循环」** 实现跑圈
5. 在模拟器中打开 **Keep App**，进入跑步页面
6. 回到 CampusRunner，点击 **「▶ 开始跑步」**

### 7.2 跑步中

| 操作 | 效果 |
|------|------|
| 点击 ⏸ | 暂停 GPS 更新 |
| 再次点击 ⏸ | 继续跑步 |
| 点击 ■ | 停止跑步 |

### 7.3 GPS 注入原理

每次 GPS 更新（默认每 1.5 秒）：

1. **平滑速度控制**：从 0 渐进加速到目标配速，模拟真实起步
2. **OU 漂移**：在真实坐标周围产生有记忆的随机游走（而非简单跳变）
3. **卫星仿真**：随机生成 8-16 颗卫星的仰角/方位角/信噪比数据
4. **位置注入**：通过 LDPlayer 的 `ldconsole locate` 命令写入 GPS 硬件层

### 7.4 跑步中观察指标

- **速度折线图**：蓝色折线实时更新，虚线为目标配速参考线
- **环形进度**：灰色底弧 + 蓝色进度弧 + 中心百分比
- **地图**：蓝色圆点标记实时位置

## 8. 跑步数据与图表

### 8.1 速度折线图

- **X 轴**：已跑距离（km）
- **Y 轴**：实时速度（km/h）
- **蓝色区域**：速度变化范围

### 8.2 环形进度

- 显示当前路线完成百分比
- 中心数字为百分比和距离
- 下方显示剩余距离

### 8.3 跑步结束后

1. 当日日期在打卡日历上**蓝色高亮**
2. 跑步记录自动添加到**历史列表**（距离/时间/配速）

## 9. 路线管理

### 9.1 保存路线

1. 加载或绘制好路线后
2. 点击底部 **「保存路线」**
3. 选择保存位置和格式：
   - **JSON**：CampusRunner 自有格式，推荐
   - **GPX**：标准 GPS 交换格式，可用其他软件打开
4. 下次启动软件可直接加载

### 9.2 加载路线

1. 点击底部 **「加载路线」**
2. 选择之前保存的 `.json` 或 `.gpx` 文件
3. 路线立即加载到地图

### 9.3 GPX 互操作

CampusRunner 支持标准的 **GPX 1.1** 格式：

- **导出 GPX** → 可导入到 Garmin、Strava、Google Earth 等
- **导入 GPX** → 从其他设备/app 记录的路线可在 CampusRunner 中使用

## 11. 高德地图 API 配置

### 11.1 申请 API Key

1. 打开 [高德开放平台](https://console.amap.com/dev/key/app)
2. 注册/登录高德账号
3. 点击「创建新应用」
4. 应用名称：`CampusRunner`
5. 应用类型：选择「工具」
6. 点击「添加 Key」
7. Key 类型：选择 **「Web 服务」**
8. 提交后获取 Key

### 11.2 配置到软件

1. 打开 CampusRunner
2. 点击侧边栏 **「⚙ 设置」**
3. 在「高德 Key」输入框中粘贴 API Key
4. 点击「保存」

或者直接编辑 `config.json`：

```json
{
  "amap_api_key": "你的高德Key"
}
```

## 12. 常见问题

### Q1：软件启动后闪退

**A**：检查是否安装了依赖：

```bash
pip install customtkinter tkintermapview
```

### Q2：连接模拟器一直失败

**A**：按顺序检查：
1. 模拟器是否已启动
2. USB 调试是否开启
3. 手动执行 `adb devices` 查看设备列表
4. 检查 `config.json` 中 `adb_path` 是否正确
5. 尝试手动连接：`adb connect 127.0.0.1:5555`

### Q3：Keep 不显示位置变化

**A**：三个可能原因：

1. **Google Play Services 未安装** → 按照 [1.2 节](#12-雷电模拟器设置) 安装
2. **模拟器定位权限未开启** → 检查设置 > 应用 > Keep > 权限 > 位置
3. **Keep 版本问题** → 尝试从 Google Play 商店更新到最新版

### Q4：地图加载很慢

**A**：
1. 点击地图工具栏的地图名称按钮（如「CartoDB Lite」）切换瓦片源
2. 已浏览过的区域会自动缓存到本地，第二次打开会很快
3. 等待瓦片下载完成（首次使用需要下载）

### Q5：路线画错了怎么办

**A**：
- **右键**删除最后一个点
- 点击 **「✖ 清除」** 删除所有点重新画
- 画好后点 **「✓ 完成路线」**

### Q6：如何确保不被检测

**A**：
1. 配速设置在 5'30" ~ 7'30" /km 的合理范围内
2. 距离设置在 2 ~ 10 km
3. 不要在极短时间内完成长距离（速度会自动平滑过渡）
4. GPS 漂移算法模拟真实定位误差
5. 避免在多个设备同时登录同一账号

### Q7：exe 文件太大（37 MB）

**A**：
- exe 包含 Python 解释器、所有依赖和地图组件
- 这是 PyInstaller 单文件打包的正常大小
- 无需安装 Python 或其他依赖

### Q8：支持哪些运动 App

**A**：

| App | 状态 | 备注 |
|-----|------|------|
| Keep | ✅ 已测试 | 需要 Google Play Services |
| 咕咚 | ✅ 理论支持 | GPS 模拟兼容 |
| 悦跑圈 | ✅ 理论支持 | 需要测试 |
| 小米运动健康 | ✅ 理论支持 | 不需要 Google 服务 |
| 华为运动健康 | ✅ 理论支持 | 不需要 Google 服务 |
| 闪动校园 | ⚠️ 注意 | 有强反作弊，不推荐 |

### Q9：可以多开模拟器同时跑吗

**A**：理论上支持。需要使用 `config.json` 中不同的 `device_addr`，启动多个 CampusRunner 实例。

### Q10：软件更新后如何迁移数据

**A**：
- **路线文件**：复制 `routes/` 文件夹
- **配置文件**：复制 `config.json`
- **历史记录**：目前保存在内存中，关闭后清空
